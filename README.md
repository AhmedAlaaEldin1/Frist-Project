# 📊 Superstore Sales Analysis – Power BI Project

## 🎯 Project Aim
To turn raw Superstore sales data into actionable insights through interactive, user-friendly dashboards that support smarter business decisions.

## 🛠 Tools & Technologies
- Power BI
- DAX (Data Analysis Expressions)
- Data Modeling
- Data Visualization

## 🧠 Key Features
- Clean and dynamic dashboard layout
- Slicers for flexible filtering and user interaction
- Visuals including bar charts, pie charts, KPIs, and line graphs
- Custom measures and calculated columns using DAX
- Conditional formatting to highlight key metrics
